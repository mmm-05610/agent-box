# Ownership Matrix v0.1

| Concern | Authoritative owner |
| --- | --- |
| Work identity/objective/closure | Work Core / host closure policy |
| Execution identity/projection | Execution Core, based on provider observation |
| Native session/transcript | Harness/Codex provider |
| Native workflow state/checkpoint/retry | Workflow provider |
| Scheduling/orchestration/notifications | Host application or extension |
| Workspace lifecycle | Workspace provider |
| Artifact bytes | Artifact authority |
| Credentials/permissions | provider and host security authority |
| Event ledger | Agent-Box runtime |
| Refs | Core runtime typed pointers |
| Provider capabilities | registered provider |
