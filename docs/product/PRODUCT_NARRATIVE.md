# Agent Box 产品叙事

> 文档导航：[总目录](../README.md)

## 产品定位

Agent Box 是一个面向本地 AI Agent 的运行与协作环境。它统一管理不同类型的
Agent，为每个 Agent 建立独立、完整且可持续演化的工作环境，并在此基础上提供
资源共享、通信与协作能力。

Agent Box 的演进主线是：**先隔离，再连接。**

## 第一阶段：隔离

Agent Box 将每个 Profile 视为一个由系统管理的 Agent 实例，而不只是一组临时
启动参数。每个 Profile 都拥有独立、持久化的逻辑运行环境，包括：

- Agent 类型、模型、供应商、环境变量、系统提示词与 Style；
- Skills、Commands、Hooks、MCP 等系统级能力与原生配置；
- 进入不同项目后，各自独立的项目级配置、规则、权限、记忆与运行状态。

同一个 Profile 在不同项目中拥有不同的项目现场；不同 Profile 即使使用同一种
Agent、进入同一个项目，也不会共享或污染彼此的配置与状态。

底层 Agent 仍然按照原生方式读取 `.claude/`、`.codex/` 等配置入口，不需要感知
Agent Box 的存在。从 Agent 的视角看，它拥有一套完整、纯净、独立的工作环境，
如同独享自己的本地运行时。

第一阶段的目标，是让多个 Agent 能够在同一台机器上长期、稳定地独立工作，并使
每个 Agent 的身份、能力和项目现场都可以被保存、恢复和持续维护。

## 第二阶段：连接与协作

隔离不是最终目的，而是可控连接的前提。当每个 Agent 都成为边界清晰的独立主体
后，Agent Box 将进一步建立它们与本地环境、公共资源及其他 Agent 之间的连接。

### 公共资源与能力

Agent Box 可以统一注册代码托管平台、云服务器、数据库、部署环境、知识库和通用
工具等公共资源，并描述它们的用途与使用方式。Agent 在获得授权后，可以在不同
项目和新会话中发现并使用这些能力，而不需要用户重复提供相同的背景和操作说明。

公共资源统一定义，但访问范围仍由每个 Agent 的权限边界控制。

### Agent 间通信

Agent Box 将为不同类型的 Agent 提供统一的通信能力，包括发现 Agent、发送消息、
分配任务、延续会话、返回结果、观察状态和取消执行。独立的 Agent 因而可以交换
信息、相互配合，并共同完成更复杂的任务。

### 自由组织协作方式

Agent Box 不规定固定的工作流，也不替用户决定 Agent 应当如何分工。它提供身份、
环境、资源和通信等基础设施；用户可以在这些基础能力之上组织主从协作、并行执行、
相互评审、图式编排或其他协作方式。

第二阶段的目标，是让彼此隔离的 Agent 在清晰、可控的边界内形成一个能够共享能力、
相互通信并有组织完成任务的本地协作系统。具体机制将在持续验证中逐步收敛。

## 持续演进

第一阶段与第二阶段代表能力建设的重心，而不是严格割裂的版本边界。Agent Box 会
持续完善单个 Agent 的隔离环境，同时逐步验证和建设多个 Agent 之间的连接与协作
能力，两部分在迭代中相互促进。

## 一句话总结

**Agent Box 先让每个本地 Agent 成为环境完整、边界清晰的独立主体，再把这些主体
连接成一个能够共享资源、通信和协作的系统。**
