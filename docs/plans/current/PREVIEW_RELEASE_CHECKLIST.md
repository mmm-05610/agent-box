# Preview release checklist

Status: open — 2.0.0a1 Developer Preview release gate.

- [ ] Review and create a clean checkpoint from the working tree.
- [ ] Confirm ACS recovery materials and approve final submodule deletion.
- [ ] Run controlled Native Codex rehearsal with a temporary home/repository;
      never expose credentials.
- [x] Adopt the coordinated 2.0.0a1 Preview version policy; Pi remains example-only.
- [ ] Build and inspect Root plus all five official plugin wheels.
- [ ] Record offline/browser Preview evidence and an external user smoke test.
- [ ] Publish only after rehearsal, checkpoint review, and artifact checks pass.

LangGraph, GitHub, Sandbox, and other workflow integrations remain future
external Hosts; they are not release checklist completion claims.
