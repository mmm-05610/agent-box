# P16 — Hook 管理面：一个外壳，逐家独立模型，**全部可编辑**

基线：P15 之后（串行）。配对后端单：**59**（逐家 schema、物化、触发账本）。
**本单的最高纪律（用户 2026-09-16 裁定）**：**所有设置都不能只是只读**——hook 必须能**增删改启停**；
某家确实不支持的事件 → **明说"该家不支持"**，**不摆点不动的控件**。

```text
之前
└── hook：产品里没有管理面（Claude Code 自己的 /hooks 菜单也只是只读浏览器）
之后
├── Hook 列表      ◀ 按家族分组：名称 / 事件 / 命令（原文可见）/ 超时 / 启用开关 / 来源
├── 编辑器         ◀ 逐家表单（claude-code 声明式；opencode 代码资产；codex 按 59 实测形态）
└── 触发记录       ◀ 什么时候哪个 hook 跑了、退出码、输出摘要；**阻断如实标注**
```

## A 列表与编辑（逐家模型）

- **外壳统一、模型分开**：顶部一个家族选择器；切换后表单**按该家 schema 重建**（事件清单与字段不同）。
- **Claude Code**：事件（按 59 取证清单）→ 匹配器（可选，注明哪些事件不支持匹配器）→ 处理器
  （`command`/`http`/…）→ 字段（`timeout`/`async`/`statusMessage`）；**默认值按官方口径显示**（不要自己编）。
- **OpenCode**：**代码资产**形态——上传/粘贴插件源码 + **摘要 + 预览** + 加载位置说明；
  **不做表单拼装代码**（界面要说清"这里放的是代码"）。
- **Codex**：按 59 阶段 A 的实测结论渲染；**结论出来之前**该项显示"待实测"，**不给假表单**。
- 门：**G1** 切换家族后表单与校验都换（有证据）；**G2** 非法配置**保存前**被拒且给出原因；
  **G3** 不支持的事件/字段**明说**，无死控件。

## B 启用与安全

- hook **默认不启用**；启用时必须能看到**完整命令**与它绑定的事件，并有明确确认（它会在沙箱里执行）。
- **运行位置如实说明**：hook 在**沙箱内**、用该次执行的隔离与网络姿态运行，**不在宿主直跑**。
- 门：**G4** 未启用不生效（有反例）；**G5** 界面**零凭据内容**（只显示引用状态）。

## C 触发记录

- 每条记录：hook 名称、事件、**时间**、**退出码**、**输出摘要（有界）**；`exit 2` 这类
  **阻断语义明确标注**（例如"本次工具调用被该 hook 阻断"），**不得**显示成普通成功。
- 门：**G6** 阻断与非阻断在界面上**可区分**（有第一手证据）；**G7** 输出摘要**有界**且经扫描（零凭据）。

## D 回归与收口

- 既有设置页用例不退化；补"未启用不生效""不支持即明说""阻断可区分"的反例；更新 status/evidence；释放写权。

## 边界

- 后端（59）负责：逐家 schema、存储与校验、物化、触发账本；本单只做交互与展示。
- **不做**统一 hook 抽象（三种东西压成一种 = 假统一）；**不做**表单拼装代码；**不做**写用户原生配置；
  **不做** wire 变更（只消费 59 的面）。
