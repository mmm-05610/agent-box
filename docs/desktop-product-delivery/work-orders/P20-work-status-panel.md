# P20 — 工作状态浮窗（收起单行 / 展开五卡；**只学交互逻辑，风格沿用现有**）

基线：P19 之后（同一工作树串行）。**新面板**，不改 legacy HUD。

## 风格纪律（用户 2026-09-17 裁定的第一要求）

- **只学交互逻辑，不抄组件代码**：参考项目里能带走的只有"**怎么交互**"；
- **视觉沿用本应用现有风格**（现有 Card/Badge/分隔线/Tailwind 令牌、`chat/status-row`、
  `tool/run-ticker` 的既有样式）——**不是"必须 Hermes 风"，而是"必须和别的 UI 契合"**；
- **不引入新视觉语言、不引入新依赖**（现有 shadcn/radix + `motion` 足够做收起/展开）；
- **不得出现"拼装感"**：门里加一条**并排截图对照**（浮窗 + 会话区 + 设置页），确认观感一致。

## 交互逻辑（本轮取证到的，逐条给"学什么"）

### ① Git 卡 —— 学 **Goose `GitBranchIndicator.tsx`**（Apache-2.0；只取其逻辑）

- **紧凑显示当前分支**；点击展开**下拉**；
- 下拉里有**搜索框（自动聚焦）**过滤分支、**当前分支打勾**、分隔线；
- **切换分支时**有进行中状态，失败**用 toast 报错**（不静默）；
- 切换前提示"**你可能还有未提交的更改**"（把风险说在前面）；
- **窗口重新聚焦时刷新**（`focus` 监听 + `cancelled` 标志可取消 + 卸载时移除监听）。
  → 我们的 Git 卡照此：分支 chip → 下拉（搜索/打勾/切换）→ 未提交提示 → **聚焦刷新**。
  **但数据面我们还没有**（见 §数据），卡内先诚实占位。

### ② 进度/用量 —— 学 **OpenHands `budget-progress-bar.tsx`**（MIT；只取其逻辑）

- 一条**细进度条**（`h-1.5` 圆角），宽度按 `current/max` 夹到 100%；
- **>80% 变红**（近限预警），带过渡动画；
- **只渲染给到的数**——没有数字就不画。→ 用在"目标卡 3/5"与用量环的进度语义上。

### ③ 子代理/任务分组 —— 学 **claudecodeui `SubagentPanel.tsx` 的形态**（AGPL-3.0，**只学形态，禁抄码**）

- **把子代理活动从主转写里分离出来**，集中到一个面板，每项带状态；
- 组**可折叠**；主转写里只留一行"启用了 N 个子代理"。→ 我们的"子智能体卡"照此形态。
  （其执行侧设计另可参考 Goose 的 `agents/subagent_execution_tool/**`，Apache-2.0。）

## 面板形态（按用户给的参考稿）

**默认收起为单行**：`● 运行中 · 4分9秒 · 更改 +108 −0 · 队列 2`（**按可用性拼**，缺项不写假值）；
点击展开为**竖排卡片**：`Git 工具` / `目标` / `进程` / `智能体（子智能体）` / `后台程序`，
每张卡标题行右侧有 `…` 与展开图标（沿用参考稿）。

## 五张卡的数据可用性（诚实边界）

| 卡 | 我们的事实 | 现在能做吗 |
| --- | --- | --- |
| **进程 / 运行态** | 队列（`agentbox-queue-panel` 的数据）+ turn 状态 + `run-ticker` 时长 | **能**（事实已在，只差这张卡） |
| **Git 工具** | **无工作区级 git 事实**（wire 28 方法无 git 面） | **不能**：本单**只定字段**（`branch`/`changedFiles`/`additions`/`deletions`/`ahead`/`behind`）供后端开单 |
| **目标** | harness 的 plan/todo 事实 → 后端单 **52** | **等 52** |
| **智能体（子智能体）** | "profile 调用 profile"（已裁定、**未开单**） | **等该项** |
| **后台程序** | 沙箱内进程清单（无事实） | **不能**：需后端面 |

**纪律**：没有事实的卡**不出现**（或只留一行说明），**不画空壳、不放假数值**。

## 阶段

**A 对照与量测**：量参考稿的收起态/展开态尺寸与间距；把上面三条交互逻辑落成"我们的行为清单"；
产出"参考元素 → 我们的数据源 → 可用性 → 交互逻辑出处"四栏表进 evidence。

**B 面板外壳**：收起态单行 + 展开态竖排卡；左上角浮动、可折叠、可关闭（记住用户选择，
沿用既有 localStorage 纪律）；动画用现有 `motion`；**样式全部取自现有令牌**。

**C 进程/运行态卡**（现在就能做）：队列项 + turn 状态 + 时长；清单部分**仅在存在清单事实时**渲染。

**D 其余四张卡**：Git 卡按 §① 的交互实现"有数据时的行为"，**数据未到即隐藏**；
目标/子代理/后台程序同样只留接口。

**E 回归与收口**：并排截图（浮窗 + 会话区 + 设置页）进 evidence；typecheck 与既有用例计数不降；
更新 status；释放写权。

## 门

| 门 | 断言 |
| --- | --- |
| **G1 对照表** | 四栏齐全（元素/数据源/可用性/**交互逻辑出处**） |
| **G2 契合** | **并排截图**证明浮窗与会话区/设置页同一视觉语言；**无新依赖**、无拼装感 |
| **G3 收起态** | 默认单行、按可用性拼、不放假值 |
| **G4 诚实** | 无事实的卡不出现（或一行说明）；不画空壳 |
| **G5 只学逻辑** | 代码里**无**任何参考项目的代码片段；许可证要求仅引用（Goose/Cline/OpenHands 可参考，
  **claudecodeui/opcode 只看形态**） |
| **G6 不碰 legacy** | `app/windows/hud/**` 与状态栏 legacy 项零改动 |
| **G7 不退化** | typecheck、既有 JS/e2e 计数不降；保护路径零改动；后端仓零写入；不碰 main、不 merge、不 push |

## 边界

- **不做**后端事实（git 状态面、52 的 plan/todo、子代理、进程清单）；
- **不做** legacy HUD 的改造或复用（"无边框浮动聊天"是另一件事）；
- **不做**命令面板/快捷键面。
