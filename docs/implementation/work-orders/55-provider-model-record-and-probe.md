依赖：与 51/52/53 **共用一次 wire 重锁**（都是"记录/事件面扩展"）；B 之后与 47/48 串行（同批文件）。

## §0 目标

让"供应商/模型"成为**有事实的记录**而不是三段手打字符串：记录里带
**端点 / 认证方式 / 协议风格 / 每模型的上下文窗口与能力开关**；并提供两个**有界探测**：
**拉取模型列表**与**测试连接**。**没有来源的字段一律未知，不许填默认值冒充。**

**验收（第一手证据）**：

| 门 | 断言 |
| --- | --- |
| **G1 记录扩展** | 新字段落库并有迁移；**旧记录照常可用**（缺省 = 未知，不阻塞任何既有路径） |
| **G2 探测有界** | 拉取/测试是**有界、可取消、可审计**的一次出网：超时、响应大小上限、只打白名单端点；**凭据零日志**（含 argv/事件/证据） |
| **G3 类型化错误** | 认证失败 / 端点不可达 / 超时 / 响应格式不符 各有类型化码，可被前端翻成人话；**探测结果不写入任何配置** |
| **G4 未知即未知** | 窗口/能力没有来源时留空；**不得**内置价目或窗口默认值；有反例测试 |
| **G5 不退化** | 既有 `provider_models.*` 方法语义与既有记录不变；全量套件与四家全链门不退化 |

## §1 范围与做法

- **记录扩展（控制面，SQLite）**：在现有 `server_provider_models` 之上补
  `base_url` / `auth_style` / `wire_api` / 每模型 `context_window` 与**能力开关**；
  字段来源标注（预设 / 拉取 / 手填）一并存，供前端如实显示。
- **探测（新）**：`models.list`（拉取）与 `connection.test`（测试）两个动作：
  - **只走声明的端点**（记录里的 base URL），**只允许 https**（loopback 例外，测试用）；
  - 有界：连接/总超时、响应大小上限、条目数上限；**可取消**；
  - **凭据只从 SecretStore 取，只在内存与请求头里**；不写日志、不进事件、不进证据；
  - 返回：解析后的模型 id 列表（拉取）或"可达/不可达 + 类型化码"（测试）；**两者都不落库**，
    由用户确认后再写入记录字段。
- **wire**：与 51/52/53 **同一批重锁**（记录字段 + 两个动作）；两仓 TS 与生成工件摘要同步。
- **不做**：任何价格/计价；任何自动改写配置文件；任何真实模型调用（探测只打 `/models` 与轻量握手，
  **不发起补全**）。

## §2 硬性规则

- 凭据：**零日志、零 argv、零证据**；探测失败的报错不得回显请求头。
- 有界与可取消；**SSRF 防护**（只 https、拒绝非声明端点、拒绝内网地址除 loopback 测试例外）。
- 不发明默认值；不放过"看起来像"的响应（结构不符即类型化拒绝）。
- 不 reset/stash/clean、不 merge main、不 push；真实模型补全调用零次。

## §3 六件套 DoD 与报告

实现 / 定向测试与反例（超时、超大响应、非 https、认证失败、结构不符、凭据零日志）/
迁移证据（旧记录可用）/ 回归计数 / status 分账 / 清理与费用账（本单费用应为 0）。
报告含：字段与来源标注、两个动作的边界参数、类型化码表、两仓摘要、未做项。
