# Archived material

This directory is for historical research, superseded implementation plans,
old validation records, and preserved design context. Archived documents are
not supported runtime architecture and must not be used as packaging or CI
inputs.

The current architecture is documented by `docs/architecture/ARCHITECTURE.md`, the Plugin
SDK guide, official plugin READMEs, and the frozen contracts under
`docs/contracts/work-core/v0_1/`. References to former `gui-web/`, ACS,
TUI, WorkBoard, or spike paths in historical records describe past states only.
