## 2. 布局与视觉计划

### 结构

参考的主识别特征是：浅灰导航、白色内容、大面积留白、紧凑单行列表、底部悬浮式大圆角输入区。不是卡片仪表盘，也不应把每条助手消息装入有色卡片。

```text
窗口栏（沿用宿主窗口能力）
┌────────────────┬────────────────────────────────────────┐
│ 品牌/轻量入口  │ 当前会话标题                    区域按钮 │
│ 新对话         ├────────────────────────────────────────┤
│ 项目与会话     │                                        │
│ 分组/滚动      │   空态 或 居中限制宽度的对话内容         │
│                │   用户右侧气泡；助手左侧自然正文         │
│                │   工具与审批属于当前对话                 │
│                │                                        │
│                │   项目上下文条（适用时）                 │
│                │   输入框                         发送/停 │
├────────────────┤                                        │
│ ● 服务器/harness│                                        │
└────────────────┴────────────────────────────────────────┘
```

上述左下 connection 是用户明确指定的 Ordessa 适配，不是截图中账号栏的业务复制。默认仅显示一行状态，点击才打开向上浮层。截图的右侧/底部工具面板是可选区域；本轮不凭截图补造浏览器、终端、diff 或子会话。

## 4. 本轮范围边界（供审批）

### A. 建议纳入：已有能力的布局与外观

- 左栏合并呈现现有项目/会话导航；列表密度、选中/运行/待响应状态与参考统一。
- 左下 connection 一行状态，默认收起、向上展开，保留当前选择与重连；服务器/harness 的具体呈现须服从现有数据契约。
- 白色主区、居中对话宽度、用户气泡/助手正文分层、底部输入框；保留发送、停止及草稿语义。
- 通用工具过程与结果采用轻量折叠；失败与未知不能混为已完成。
- 审批/提问维持在当前对话内，给出清楚状态和真实可执行按钮。
- 已有工作台区域的边界、图标按钮与折叠外观；无视图的区域不提供虚构工具。

### B. 需要确认后才可写入实施范围

- 服务器和 harness 是两级选择还是单列表组合标签：已核实的状态栏目前只有 connection 列表，不能凭 UI 新造服务器管理接口。
- 审批卡位于对话顶部提示区，还是嵌入对应消息时间顺序：现有卡片属于对话组件但在消息 viewport 之前，后者可能需要顺序/关联信息。
- 搜索、分组折叠、项目浮层、置顶/归档动作、快捷键、创建项目：逐项核对业务契约；显示已有 pinned 字段不等于支持置顶写操作。
- Markdown、代码高亮、复制按钮、文件链接如何安全打开：现有文本 primitive 的接线不证明完整富文本能力。
- 小窗口最小宽度、侧栏收起断点、浮层焦点与键盘规则；参考图仅覆盖桌面宽屏。
- 是否需要保留具体右侧/底部视图入口；本轮没有浏览器/终端/diff 能力实现授权。

### C. 排除

账号、语音、探索、PR、定时任务、计费、插件市场、目标管理、子 agent 管理、完整设置系统；新增 provider/model/推理强度配置；浏览器/终端/diff/分支/Git 操作的新业务；后端契约或数据结构变更；主树集成、推送、发布。截图里的产品名、图标品牌、真实会话内容不作为要复制的数据。

## 6. 审阅标准与自检

本方案识别点是 Codex 的导航/正文/输入区比例，不是新增装饰。已将技能默认的“独特展示字体/创新视觉”收敛为截图中的系统无衬线与克制灰阶；把账号栏替换成用户要求的 connection；移除无现有业务支撑的导航项与模型菜单。右侧面板不承担常驻审批职责。

用户审阅时应确认：布局比例、左下 connection 的服务器/harness 表达、审批在对话中的具体位置，以及 B 类条目是否加入下一轮。即使文档分析完成，也不代表用户已接受 UI 或授权实施。

后续若获实施授权，验证应覆盖空态、选中历史会话、运行/停止、工具展开/失败、审批待答/终态、连接断开/恢复、小窗口和键盘焦点；截图仅比较匿名测试内容，不沿用参考中的私有会话。当前交付仅新增本文档。
