# GitHub CLI `gh skill`

Maintainer: GitHub CLI, https://cli.github.com/manual/gh_skill. CLI has search, preview, install, list, update and publish dry-run. Source is GitHub repository/local directory; target is user or project native path and can name an agent. Identity is repo + skill slug, with version syntax supported by the command surface; commit/digest lock, rollback, symlink, CAS, dependency, signing and bidirectional sync are UNKNOWN. It copies content and supporting files to native targets; project skills remain project-owned. Activation and conflict semantics are delegated to each host. Existing installed content works offline; registry outage affects discovery/update only. Installation is a download boundary, but script execution during install is not claimed. Tier A/B; see S6.
