# OpenAI API Skills

Official API reference: https://developers.openai.com/api/reference/go/resources/skills. This is a remote project-scoped service, not Codex's local directory. It stores skill objects by API ID, exposes content zip download, creates immutable versions, lists/deletes versions, and updates a default version pointer. It is the clearest official registry/version model in the evidence. Local projection, native harness paths, project Git behavior, scripts/trust, signatures, offline cache and deletion semantics are outside this API page and UNKNOWN. Tier B; see S13.
