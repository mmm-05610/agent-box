# omrikais/skill-manager

Official repo: https://github.com/omrikais/skill-manager. CLI/TUI `sm`; license and current commit must be checked before production adoption. SSOT is `~/.skill-manager/skills`; Git sources are cloned under `sources/` and tracked in `sources.json`. Identity is slug plus source URL; SHA-256 detects changed content, but no immutable version/ref lock or CAS is documented. Deployment uses atomic symlinks; auto-adopt scans native user and project paths, imports content, removes original and links it back. Project ownership can therefore be silently converted to central ownership, a deliberate but risky divergence from Agent-Box direction. Numeric suffixes resolve conflicts. Updates prompt/skip/force; no true rollback, signature, dependency, bounded import or script sandbox claim. Tier C; see S12.
