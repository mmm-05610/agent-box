# madebywild/agent-harness

Official repo: https://github.com/madebywild/agent-harness; maintainer madebywild; MIT and active. Canonical source is project `.harness/src`; Git registries are pulled into editable project source with provenance. Identity is typed entity id/sourcePath; lock records source hashes and registry Git revision; output hashes and ownership are tracked. `apply` plans create/update/delete and blocks unmanaged/colliding output; watch is one-way source-to-target. It renders provider-specific copies, not symlinks/CAS. Project source is canonical and not auto-promoted to a global store. Activation is manifest/provider enabled state. Rollback is Git/old source; offline uses local source. Scripts/hooks are a special risk; license/signature/dependency and runtime session drift are not fully solved. Monorepo targets are supported. Tier B/C; see S10.
