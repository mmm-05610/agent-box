# Skilldex (supplementary)

Research project: https://arxiv.org/abs/2604.16911. Reported design includes a TypeScript CLI/package manager, metadata-only registry, hierarchical scopes and MCP server. It is not treated as mainstream or official harness behavior; repository identity, license, deployment security, code maturity, reproducible revision/rollback and real CLI behavior require separate verification. Tier D only. Included to show that registry/CAS-like ideas exist outside the mature native ecosystem.
