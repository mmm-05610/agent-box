# Source policy

Tier A = official documentation + official source + repeatable experiment. Tier B = official documentation or source. Tier C = active implementation plus repeatable local observation. Tier D = community discussion or secondary report. UNKNOWN is used when evidence is absent; it is not treated as false.

Primary evidence was preferred for harness behavior and project identity. Search snippets were not used as sole support for a recommendation. Dynamic facts are dated 2026-09-02 and marked version-sensitive. URLs in the ledger are stable entry points; exact file paths and sections are recorded where available.

No credential-bearing directory was scanned. No skill script was executed. Remote repositories were researched through public documentation/source pages; no product repository was altered.
