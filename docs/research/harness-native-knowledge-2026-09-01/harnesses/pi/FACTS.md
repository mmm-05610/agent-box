## C. Launch Modes

- **C.1 Interactive TUI (default).** `pi` or `pi "initial prompt"`, `@file` args attach files/images; `--tui-mode regular|fullscreen`. [OFFICIAL_DOC README; H; STABLE]
- **C.2 Headless print (`-p` / `--print`).** `pi -p "prompt"`: runs the prompt, prints final assistant text to stdout, exits. Exit code 0 on success; **1 if last assistant `stopReason` is `error` or `aborted`** (error text on stderr) or on exception; SIGTERM→exit 143, SIGHUP→129. Piped stdin is merged into the initial prompt (`cat x.md | pi -p "Summarize"`). Prompt starting with `-`: `pi -p -- "-text"`. [OFFICIAL_SOURCE packages/coding-agent/src/modes/print-mode.ts:33-168 + OFFICIAL_DOC README; H; VERSION_SENSITIVE]
- **C.3 JSON event stream (`--mode json`).** `pi --mode json "prompt"`: first stdout line is the session header `{"type":"session","version":3,"id":"<uuid>","timestamp":"...","cwd":"..."}` followed by event lines (see H). Same exit semantics as print mode. [OFFICIAL_DOC docs/json.md; H; VERSION_SENSITIVE]
- **C.4 RPC mode (`--mode rpc`).** Long-lived process, LF-delimited JSONL commands on stdin / responses+events on stdout (`pi --mode rpc [options]`). Full command set: prompt, steer, follow_up, abort, clear_queue, new_session, get_state, get_messages, set_model, cycle_model, get_available_models, set_thinking_level, cycle_thinking_level, get_available_thinking_levels, set_steering_mode, set_follow_up_mode, compact, set_auto_compaction, set_auto_retry, abort_retry, bash, abort_bash, get_session_stats, export_html, switch_session, fork, clone, get_fork_messages, get_entries, get_tree, get_last_assistant_text, set_session_name, get_commands. Optional `id` field correlates responses. **Framing gotcha (documented): split on `\n` only; Node `readline` is non-compliant** (splits U+2028/U+2029). [OFFICIAL_DOC docs/rpc.md; H; STABLE]
- **C.5 SDK.** `createAgentSession()` / `AgentSession` / `SessionManager` from `@earendil-works/pi-coding-agent` for in-process embedding. [OFFICIAL_DOC docs/sdk.md + README; H; VERSION_SENSITIVE]
- **C.6 Observed RPC smoke probe (no model call):** `printf '{"id":"r1","type":"get_state"}\n' | PI_OFFLINE=1 pi --mode rpc --no-session --provider deepseek --model deepseek/deepseek-v4-flash` → response with full model catalog entry (`baseUrl https://api.deepseek.com`, `api openai-completions`, `reasoning: true`, contextWindow 1000000, maxTokens 384000), `thinkingLevel: "high"` (default for this model), generated `sessionId` uuid, exit 0, empty stderr. `get_available_thinking_levels` → `["off","low","high","max"]`. ## F. State Isolation

- **F1.** Session files: `~/.pi/agent/sessions/--<cwd-with---/>--/<timestamp>_<uuid>.jsonl`. [OFFICIAL_DOC docs/session-format.md:7-11; H; STABLE]
- **F2.** Format: JSONL, header v3 `{"type":"session","version":3,"id":"<uuid>","timestamp":ISO,"cwd":"..."}` (+ `parentSession` for forks), then tree entries with 8-hex `id`/`parentId`. Entry types: `message` (AgentMessage: user/assistant/toolResult/bashExecution/custom/branchSummary/compactionSummary), `model_change`, `thinking_level_change`, `compaction`, `branch_summary`, `custom` (extension state, not LLM context), `custom_message` (in context), `label`, `session_info` (display name). Assistant messages carry `provider`, `model`, `usage` (tokens + cost), `stopReason`. Old files auto-migrate v1/v2→v3 on load. [OFFICIAL_DOC docs/session-format.md; H; VERSION_SENSITIVE]
- **F3.** Filename pattern `<timestamp>_<uuid>.jsonl` means a lookup glob `*_<session_id>.jsonl` under the session dir resolves a session id → file (Agent-Box `sessions.py` approach is structurally sound; also `--session <partial-uuid>` does this natively). [OFFICIAL_DOC + INFERENCE; H; STABLE]
- **F4.** Full guest isolation is achievable WITHOUT any home-file leakage: `PI_CODING_AGENT_DIR=<guest>` relocates settings/auth/models/skills/extensions/sessions wholesale (sessions then live `<guest>/sessions/`); `PI_CODING_AGENT_SESSION_DIR=<dir>` relocates sessions only; `--no-session` disables persistence. Observed: with `--no-session`, RPC get_state ran without creating a session file. [OFFICIAL_SOURCE config.ts:524-570 + CLI_OBSERVED; H; STABLE]
- **F5.** Deleting a session = delete its `.jsonl` (or `/resume` + Ctrl+D, uses `trash` CLI when available). [OFFICIAL_DOC docs/session-format.md:13-17; H; STABLE]
- **F6.** `~/.pi/agent/trust.json` is host-state (per-folder trust decisions) — treat as unsafe/opaque for projection. [OFFICIAL_DOC docs/settings.md:14-22; H; STABLE]

## I. Runtime Control

- **I1. Interrupt:** RPC `abort` command (continues queued messages; `clear_queue` first to drop them); TUI Escape aborts. In print mode SIGTERM→143 / SIGHUP→129 handled; SIGINT is default Node behavior (not specially handled in print-mode source). [OFFICIAL_SOURCE print-mode.ts:50-66 + docs/rpc.md; H; STABLE]
- **I2. Steer / follow-up injection:** TUI Enter (steer) / Alt+Enter (follow-up); RPC `steer`, `follow_up`, or `prompt` with `streamingBehavior:"steer"|"followUp"` (plain `prompt` during streaming errors); delivery modes `steeringMode`/`followUpMode` = `one-at-a-time` (default) | `all`; `clear_queue` retrieves+removes. [OFFICIAL_DOC docs/rpc.md; H; STABLE]
- **I3. Attach:** `@file` args (text+images), `initialImages` in RPC prompt (base64 ImageContent), piped stdin merge in `-p` (C.2). [OFFICIAL_DOC; H; STABLE]
- **I4. Permission prompting:** NONE built in ("No permission popups... Run in a container, or build your own confirmation flow with extensions"); `ask_question` tool is exclude-able; extensions can gate tool calls (`tool_call` event). Tool allow/deny: `--tools`, `--exclude-tools`, `--no-tools`, `--no-builtin-tools`, settings `defaultTools`. Headless trust handled by `defaultProjectTrust`/`-a` (C.8). Docs/`containerization.md` covers sandboxing guidance. [OFFICIAL_DOC README Philosophy + settings.md; H; STABLE]
