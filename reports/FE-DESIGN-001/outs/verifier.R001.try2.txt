## 4. Experiment

FE-CE-001's concrete user-visible claim ("a returning subscriber sees superseded seq=1 with no invalidate marker") is settleable as a pure replay model. This models only the two disputed representations, not the product or protocol.

EXPERIMENT:
```python
# Model of the disputed mechanism ONLY: snapshot-as-stream (A) vs value+invalidate (minimal form).
# Does a returning reader, given only host-provided metadata, ever surface a stale value as live?

def stream_replay(envelopes):
    # A's core Envelope: {resource_id, seq, ts, kind, payload}. No superseded/current flag exists.
    # Host guarantees ordering; content interpretation is the view's job.
    return sorted(envelopes, key=lambda e: e["seq"])

def value_replay(buffer):
    # Minimal form: read(resource_id) -> one current value, plus an invalidate signal.
    return buffer["current"] if not buffer["invalidated"] else None

# git.diff resource. Working tree changed once: old diff then new diff.
seq_log = [
    {"seq": 1, "payload": "OLD_DIFF"},
    {"seq": 2, "payload": "NEW_DIFF"},
]
value_buf = {"current": "NEW_DIFF", "invalidated": False}

# Returning page re-subscribes (from_cursor). It has NO host marker of supersession:
replayed = stream_replay(seq_log)
stream_last  = replayed[-1]["payload"]            # what a "render the latest" view picks
stream_seen  = [e["payload"] for e in replayed]   # what a "render the log" view shows as live
has_supersede_flag = any("superseded" in e for e in replayed)

value_now = value_replay(value_buf)

print("STREAM: host marks superseded?", has_supersede_flag)
print("STREAM: seq-ordered payloads offered to view:", stream_seen)
print("STREAM: latest payload:", stream_last, "| stale still present as an entry:", "OLD_DIFF" in stream_seen)
print("VALUE : current only:", value_now, "| stale present:", "OLD_DIFF" == value_now)
```
Model result: under the stream representation the host offers the reader no `superseded` marker, so whether the stale `OLD_DIFF` is surfaced depends entirely on the view's choice — the core provides no signal to distinguish it; under value+invalidate the stale value cannot appear as the current read. This shows the *model* behaved this way; it is not a verification of A, the protocol, or the product.
