# Model of the D08 dispute for FE-CE-009 only. Proves the model, not the product.
# Question: is the per-handle accumulated spawned SET load-bearing for any
# required S01-S12 outcome, or is "subscribe same-namespace" sufficient?
# S08 user outcome checked: the job spawned by h_R's own invoke is observable
# (FE-CE-004 stays closed). job2 is a same-ns resource h_R never spawned and no

    return {primary} | set(spawned)

    return requested if requested == primary or requested[0] == handle_ns else None
