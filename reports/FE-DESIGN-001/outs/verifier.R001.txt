## 4. Experiment
The disputed mechanism is representable as a small executable model of A's stream contract: append-only monotonic `seq`, `from_cursor` replay in order, and no value/snapshot/invalidate op — checking whether a returning subscriber can distinguish current from superseded from core fields.

EXPERIMENT:
```python
# Models ONLY A's disputed content-plane (cand-A §A.2, §A.5-S03 step4):
# observable content = append-only, per-resource seq-ordered envelope log with
# from_cursor replay and NO value/snapshot/invalidate op. Proves the model only.
class CoreStream:
    def __init__(self):
        self.env = {}; self.seq = {}
    def ingest(self, rid, kind, payload):      # NO is_current/superseded field
        s = self.seq.get(rid, 0) + 1; self.seq[rid] = s
        self.env.setdefault(rid, []).append(
            {"resource_id": rid, "seq": s, "kind": kind, "payload": payload})
    def replay(self, rid, from_cursor):        # host guarantees order only
        return [e for e in self.env.get(rid, []) if e["seq"] >= from_cursor]

c = CoreStream()
c.ingest("git.diff", "snapshot", {"tree": "A"})   # seq=1 old value
c.ingest("git.diff", "snapshot", {"tree": "B"})   # seq=2 current value
got = c.replay("git.diff", 1)                     # page returns at seq 2
stale   = [e for e in got if e["payload"]["tree"] == "A"]
marked  = [e for e in got if "is_current" in e or "superseded" in e]
print("count returned:", len(got), "->", len(got))
print("stale-as-live replayed at return:", len(stale) == 1)
print("core marked any supersession:", len(marked) > 0)   # -> False

class Snap:                                        # attacker's minimal fix, in model form
    def __init__(self): self.v = {}
    def write(self, rid, p): self.v[rid] = p       # overwrite = invalidate
    def read(self, rid): return self.v.get(rid)    # only current
s = Snap(); s.write("git.diff", {"tree": "A"}); s.write("git.diff", {"tree": "B"})
print("snapshot-fix current:", s.read("git.diff"))
print("snapshot-fix shows stale:", "A" in str(s.read("git.diff")))  # -> False
```

Model result (the model only, not the product): under an append-only seq-replay plane with no snapshot op, a return-later replay of a twice-updated snapshot resource returns both values, and **no core field distinguishes current from superseded**; a snapshot/invalidate store returns only the current value. This is consistent with the CE-001 mechanism but does not verify A.
