## 1a. Per established (`holds`) counterexample — the exact change that makes its sequence impossible

**FE-CE-008 (holds → CLOSED).** Verdict: the ns-scoped *envelope* `payload_schema_id` descriptor store has zero host readers once the R003 delivery gate was removed. The change: in the revised candidate §R4.2 the Envelope's `payload_schema_id` is an **opaque routing/selection label string**; there is no `register_type(ns, schema, descriptor)` store for envelope payloads. Resolver matching (§R4.4) and the generic fallback label read the envelope **string**, not a stored descriptor; typed action params/results are declared **inside `action.register` under the adapter's own namespace**, which is the surviving ns-scoped key. FE-CE-006 stays CLOSED because the only shared bare-name key (the payload store) no longer exists, and action-type isolation comes from the per-namespace action registry, not a global map. Living in: §R4.2, §R4.5-S06 step5, §R4.6.

**FE-CE-010 (holds → CLOSED).** Verdict: `invoke_id` on `OutcomeUnknown` has no host consumer after the auto-resubmit path was deleted. The change: `action.invoke(...) → ... | OutcomeUnknown` carries **no token**; the host never stores or reads an invoke correlation id. The caller correlates the unknown outcome synchronously by which `invoke` call returned. S09 dedup/reorder keys on `(ns, resource, seq)` — not `invoke_id`. Living in: §R4.2 (Typed action), §R4.5-S09 step1/3.

**FE-CE-011 (holds → CLOSED).** Verdict: `live-default-subscribe` is a parameter default, not a primitive. The change: `from_cursor` is **mandatory** on `subscribe`; the host **pair-gesture** (§R4.4) supplies `from_cursor=cursor.resolve(id)` when it mints the secondary handle, so the fresh handle starts live. FE-CE-005 stays closed because the pair-mint passes the current cursor explicitly — no replay from seq 0, no stale re-fire. Living in: §R4.2 (Event stream), §R4.4, §R4.5-S08 step4.

**FE-CE-007 (holds, carried OPEN).** Verdict: unchanged — `edges.list` on Candidate B returns core-stored foreign-namespace ids to a scoped handle; B §R003.B.3 concedes no repair preserves standing relay while closing the leak, and §R003.B.5 **withdraws the carrier, not the invariant.** This is not a cost, it is an unmet isolation invariant. The surviving candidate A has no edges mechanism, so the leak sequence is impossible there; the row stays OPEN against demoted B. Living in: best-candidate §R4.9 (B demotion rationale retained).
