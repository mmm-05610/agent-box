## C 左下角 Gateway — **台账与结论（不改代码，因为该面在产品下已经不渲染）**

- 台账：全渲染端生产代码中仍出现 gateway 符号的文件 **401 个**——它们是 **legacy data plane**（`api/*`、`store/gateway/*`、
  legacy 会话/网关面板等），服务 legacy authority。**产品 surface 侧已在上游阶段完成“删除/映射”**：
  `app/composition/registrations/statusbar-items.tsx` 的 `LEGACY_STATUSBAR_ITEM_IDS = ['agents','cron','gateway-switcher','webhooks']`，
  `visibleStatusbarItems(items, 'agentbox')` 把 `gateway-switcher` 整个丢掉，既有用例
  `statusbar-items.test.ts` 断言 agentbox 下该 id 不在可见集合内。因此产品右下/左下**不渲染 gateway 一词**，
  也没有 Idle/Disconnected 弹层入口。
- 结论（二选一之选 2）：**删除**（在产品 surface 上），保留 legacy authority 的既有面不动；不新增 product 语义的
  “服务连接”控件（那是另一件产品决定，且没有额外信息可放）。**G6 台账齐全**（本节即台账：符号归属 → 结论）；
  **G7 第一手证据**：现有 statusbar 用例 + 产品组合传 `authority='agentbox'`；**G8 删除路径无孤儿**：
  未新增引用、未留半死状态。
