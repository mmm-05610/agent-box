# P04 Electron 宿主边界证据

## 切片 1：main-only wire transport 与诚实 unavailable（2026-09-14）

本切片完成了不依赖后端启动合同的宿主工作：renderer 只提交已验证的 wire 信封；Electron
重建并约束 `/wire/v1/{method}` 目标，未来由 main-process 私有 lifecycle closure 注入 endpoint
与 session token。token 只在 HTTP dispatcher 内成为 Bearer header，不进入 preload 类型、renderer、
URL、响应或日志。

生产当前注册 `unavailableAgentBoxWireDispatcher`。这是刻意的正常状态：具体 artifact/data-root/
动态端口/readiness/token ACL/退出期限尚未锁定，故不猜 spawn 参数，也不回落 `hermes:api`。

```text
apps/desktop/electron/
├── main.ts                              ◀ 仅注册 agentbox:wire:request；无函数声明
├── preload.ts                           ◀ 独立 window.agentBoxDesktop.wire 窄桥
├── ipc/
│   └── workcore-wire-ipc.ts             ◀ 校验 method/path/envelope 一致性；不接 endpoint/header
├── security/
│   └── agentbox-wire-transport.ts       ◀ URL policy + main-only Bearer + timeout/错误边界
├── workcore/
│   ├── lifecycle.ts                     = 六动词基础设施合同；仍不含凭据/Session/Execution
│   └── slot.ts                          = 未安装生产 lifecycle，不制造实现
└── legacy-hermes/                       = 本切片零 import、零 fallback；待后续逐消费者退役

apps/desktop/src/
├── global.d.ts                          ◀ 只暴露 request；无 token/endpoint/header
└── api/agentbox-runtime-client.ts       ◀ 已有生产 client 消费该桥；缺桥即 UNAVAILABLE
```

验证：Electron 2 files / 5 tests passed；三项目 typecheck；改动文件 ESLint 0/0。测试覆盖空连接
不发送、主进程附加 Bearer、401 typed envelope 原样交客户端、危险 endpoint 拒绝、renderer 自选
path/信封不一致在 dispatcher 前拒绝。

阶段仍为 `P04_PARTIAL`：真实 lifecycle、事件订阅桥、优雅退出和默认 Hermes 启动控制流退役待续；
这些不能用测试替身或硬编码 8732 冒充完成。

## 切片 2：不透明事件订阅 IPC seam（2026-09-14）

本切片把未来 lifecycle 所拥有的事件源接到 renderer 的唯一窄桥，但没有虚构 Server 事件地址或
协议。Electron IPC 只广播 `unknown`；preload 同样不把主进程输入冒充已验证合同。renderer 在
进入 reducer 前以 `EventFrameSchema` 校验，非法帧静默丢弃；合法帧复用既有幂等/序列缺口
reducer，发现 gap 时触发服务历史补水。卸载 route surface 会注销 renderer listener，Electron
注册函数也向未来 composition owner 返回源订阅 cleanup。

```text
apps/desktop/
├── electron/
│   ├── ipc/workcore-wire-ipc.ts        ◀ 注入式 opaque source；只向存活窗口广播并返回 cleanup
│   └── preload.ts                       ◀ onEvent(callback) 窄桥；返回 removeListener
└── src/
    ├── global.d.ts                      ◀ frame 保持 unknown，禁止跨信任边界伪造类型保证
    └── app/composition/wiring/
        └── agentbox-main-chat.ts        ◀ schema 校验后入 reducer；gap 才请求 history resync
```

验证：定向 3 files / 18 tests passed；三项目 typecheck 通过；改动文件 ESLint 与
`git diff --check` 在提交前通过。测试覆盖 source 广播、已销毁窗口过滤、source cleanup、非法帧
拒绝、合法帧摄入与 route 卸载退订。

阶段仍为 `P04_PARTIAL`：生产 `subscribeWireEvents` 尚未由真实 Server lifecycle 提供，且默认
Hermes 启动控制流尚未退役。本切片不把缺少生产事件源标为 GREEN，也不以测试 source 作为默认。
