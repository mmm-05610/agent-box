## 切片 6：按 Session/cursor 所有权隔离的事件 IPC（2026-09-14）

事件桥由进程级广播收紧为 renderer 发起的 Session/cursor 订阅。preload 生成仅用于 IPC 所有权的
subscriptionId；该 id 不进入 Server transport。main 以 `webContents.id + subscriptionId` 持有源
cleanup，只把不透明帧回送发起者；无效输入、源同步失败、sender 销毁、重复退订与坏 cleanup 都不会
泄漏订阅或打断其余 teardown。

renderer 先完成 history hydration，取得非空 `resumeCursor` 后才订阅。每帧 cursor 更新不重建
WebSocket；发现 seq gap 时先停旧源，再补水并从新 cursor 重订阅。旧 Session、非法 frame、卸载后
迟到 hydration 均不能进入当前投影。同步源在返回 cleanup 前报告 gap 的竞态也会补偿释放真实源。

```text

└── src/
    ├── global.d.ts                                ◀ renderer 不见 endpoint/token/subscription owner
    └── app/composition/wiring/agentbox-main-chat.ts
        ├── hydrate → resumeCursor → subscribe
        └── gap → unsubscribe → hydrate → resubscribe
```

upgrade header，不进 URL、frame、错误或日志。它只解析 JSON 为 `unknown`，不解释 EventFrame，


> **更正（2026-09-14，切片 9 回填，原文不回填）**：上表 `connection null ... → honest unavailable`

## 切片 9：HTTP/WS 共用 loopback 判据与无连接可观测性（2026-09-14，P05 收口检查点）

本切片只改 main/security 层与 production composition，不动 renderer、wire schema、preload 或 shared。

**共用判据（新文件）**：`electron/security/agentbox-wire-endpoint-policy.ts` 是两条 transport 唯一的
endpoint 裁决处，避免同一条安全规则在两处各写一遍后漂移。`resolveAgentBoxWireEndpoint(endpoint)`
返回 `{endpoint:{origin,protocol}, reason:null}` 或 `{endpoint:null, reason:'invalid'|'non_loopback'}`，
**从不抛错、从不在失败里回显 endpoint**（endpoint 是 main-only 事实）。

| 情形 | 判定 |
| --- | --- |
| `localhost` / `::1` / `[::1]` | 允许 |
| 合法 `127/8` 字面量（四段十进制、每段 ≤255） | 允许 |
| 其他 hostname/IP（含 `127.0.0.1.evil.test`、`[::2]`、十进制编码的远端地址） | `non_loopback` |
| 非 `http:`/`https:`（`ws:`、`file:` …）、带 username/password、URL 解析失败/空串 | `invalid` |

**HTTP**：`requestUrl` 先用该判据判 endpoint，再判 same-origin 与 `/wire/v1/` 前缀；因此非 loopback 目标
在**调用 `fetch` 之前**就以既有 `AgentBoxWireHostUnavailableError` 拒绝，不会产生主机本不该发起的外连，
失败消息里既无 endpoint 也无 token（`endpoint is invalid` / `endpoint is not loopback` /
`wire request target is invalid` 三条稳定文本）。`/wire/v1/` 目标规则与 `redirect:'error'` 不变。

**WS**：无 connection、accessor 抛错、无 token 三条推导现在统一 `onError` **恰好一次**（此前是静默
no-op），并返回幂等 cleanup；非法 endpoint、WebSocket 构造失败、socket error 继续走同一诊断通道。
新增 `AgentBoxWireEventError`（`code: connection_unavailable | endpoint_rejected | socket_unavailable |
socket_error`，message 固定为 `AgentBox event stream is unavailable`）——**不附带原始 cause**，因为
原始错误可能引用 endpoint 或 token。listener 抛错与 `onError` 抛错都被吞掉，不崩 main；listener 注册
失败会关闭已建 socket 并经同一通道报告，避免半注册 socket 泄漏。

**生产诊断出口**：`createAgentBoxServiceComposition` 在调用方未传 `onEventError` 时使用默认 sink，
**只记录稳定类别**（`[agentbox-wire] event stream <code>`），绝不输出 connection 或 token；
调用方可覆盖为自定义 sink（同一限制）。

**边界**：本切片不发明 renderer 业务事件，也不把 transport 失败伪装成 Session 终态——wire 事件流失败
仍只是失败，Session 终态只能由服务帧产生。

```text
apps/desktop/electron/
├── security/agentbox-wire-endpoint-policy.ts       ◀ 新增：HTTP 与 WS 共用 loopback/协议/凭据判据
├── security/agentbox-wire-transport.ts             HTTP：fetch 前拒绝 + 稳定失败文本
├── security/agentbox-wire-event-transport.ts       WS：三条无连接推导各报告一次 + typed code
└── composition/agentbox-service-composition.ts     默认安全 sink（仅类别）
```
