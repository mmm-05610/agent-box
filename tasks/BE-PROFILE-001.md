# BE-PROFILE-001 — Profile 独立能力：职责盘点与拆分方案

签发：I，2026-09-22。用户已确认方向并要求派工。
接收者：中央 C；由 C 协调 S/E/H，必要时征询 P。状态：ISSUED，待 C ACK。

## 已确认方向

Profile 应成为独立能力，拥有身份、版本、持久化、配置组合及固定快照。
H 只负责 Harness 特有配置的声明、校验和原生转换，不拥有 Profile 权威存储。
Profile 能力保存凭据引用而非秘密内容，秘密解析与运行时投影仍走既有授权边界。
独立能力不预设为独立进程、仓库或一个新的执行组，也不把各家原生逻辑全部搬入它。

- S：盘点 server/profiles、模型配置、会话受理的 Profile 身份、版本、读写者和冻结时点。
- H：盘点 generic/ProfileStore、ProfileSelector、ProfileManager、profile envelope、原生 materialization；
  将通用管理与 Harness 特有转换区分，列出真实调用方，不以同名证明重复。
- E：确认执行消费的固定快照/引用及生命周期，避免自己读取“最新 Profile”或维护第二份权威配置。
- P（如涉及）：说明秘密引用解析、临时原生文件投影、租约与释放的责任，不接管 Profile 业务。
