## 批准的结构

以下是逻辑模块，语言后缀与物理包名由 C/H 按现有构建约定落实；不要求制造空文件。

```text
plugins/
  agent-box-harness/
    src/                 plugin / registry / provider / contracts
    runtime/
      entry.mjs
      acp/               connection / sessions / events / capabilities /
                         extensions / callbacks
    tests/
  agent-box-harness-<agent>/
    manifest             身份、启动方式、版本、依赖
    configuration        专属配置声明、校验、原生转换
    extensions/          按需：已批准的扩展契约与绑定
    adapter/             按需：Agent 端 ACP 适配，优先复用
    tests/
```

核心只认识 ACP、接入包契约、注入接口，不认识具体品牌或宿主实现。
callbacks 只做协议校验/映射/路由/响应，不实现文件、终端、权限策略等宿主能力。
标准能力按实际处理器与当前上下文授权声明；存在处理器不等于允许调用。
不以任意方法透传或动态模块加载绕过范围、能力协商、校验或权限。

## 禁止隐藏职责

不在核心或任意 agent 包内新建通用文件读写服务、终端管理器、沙箱/SSH/进程管理器、
Profile CRUD/版本/权威存储、凭据仓库、权限策略引擎或工作流编排器。
不能通过改名为 helper/adapter/extension、复制到各家目录、嵌入 vendor 补丁等绕过。
Agent 配置生成可产出声明/配置内容，通用路径授权、落盘投影、租约/回收交外部所有者。
专属历史/认证兼容逻辑只在确属该 Agent 接入时保留，不借此读取任意宿主文件或秘密。
需要外部能力却没有提供者：声明缺失并报告接口需求，不在 H 内兜底实现。
