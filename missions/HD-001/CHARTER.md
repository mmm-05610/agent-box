# 范围、授权与验收
## 今晚唯一目标
前端可插拔业务包抽离，连接后端后在连接区域临时二级选择 Harness，整机成为该 Harness Desktop。无会话级 Harness 选择，无跨 Harness 混排/并行管理。
独立会话或选项目后建会话；打开历史、多轮流式对话、工具调用/结果、服务实际提供的思考、Agent 产出、真实审批/输入响应、停止和断连如实显示。
同一 Harness 内多会话；切换不等于取消。运行或待审批时先禁止切换 Harness；以服务事实判定，不能凭页面是否打开猜。
独立会话执行目录明确，项目目录来自用户选择/后端权威。不得让真实测试写产品源码或用户项目。基础闭环先 Pi/ Codex，不为支持全部品牌阻塞交付。

## 不做
不开发/迁移/扩张 Profile、Provider、Model、配置管理、思考强度设置；不延续旧 Profile 清理任务。不新增浏览器、终端、Git 工作台、完整文件/产物管理器、自动化、市场。
预留契约仅针对明确需求，不创建空壳插件/占位入口。已有配置服务可被既有启动链使用，不以本轮为由改造它。
不要强制审批占右栏。学习参考项目后决定交互布局；基础风格借鉴 zcode/Codex，右/下区没有范围内功能就不展开。复用与统一风格同时满足。

## 测试的特别授权
用户现已授权在预算内进行真实模型测试与必要的测试专用启动配置：
Codex 测试每次显式指定 gpt-5.6-luna，不允许回退默认模型；Pi 原样用已有配置，不改模型/认证/默认配置。
其他 Harness 仅使用用户已保存的 DeepSeek key；key 不是 endpoint 或 model ID，先从公开资料/明确非秘密配置证据核实，不猜测第三方端点，不把 key 发给未知域名。不确定时延后该 Harness，用 Pi/Codex 推进。
只有 C 指定的测试运行者可读取密钥并在内存注入；必要测试配置可在 /home/maoqh/.config/ordessa-testing/hd001/ 内以 0700/0600 最小化保存，优先只保存路径/非秘密项。禁止打印、入 Git、进报告、进提示词、set -x 或详细 HTTP auth 日志。
使用既有登录仅限官方 Harness 原生消费，禁止研究/扫描凭据内容。API key 不授予其他秘密访问权。
审阅模型仅 C 调度 gpt-5.6-sol，是测试 luna 限制的明确独立审阅例外，不得用作 Harness 测试替代。
允许 C 批准启动本任务专属 loopback 服务、隔离测试目录、独立状态库与 Electron 测试；登记端口/PID/start-time/数据根/退出方式。不能启停原有服务。只清理精确登记的本任务进程。
浏览/下载公开源码可直接做；无全局安装、系统权限更改或未知许可引入。审批模型待用户选择的操作只在无破坏临时场景中测试，不自动批准真实危险操作。

## Git与验收
不 push、不覆盖发布 main、不 reset/stash/clean、不删旧树、不丢旧成果、不 git add -A。
仅执行者提交自己批准文件，FC/BC 在各自新集成树集成停写交付。允许中央代提交须有明确停写+准确文件摘要+暂存区核对，沉默不算停写。
用户已满意旧原型，不动其验收树。代码/夹具/真实进程/真实模型/Electron 完整链路证据分开。
C 交付可运行 FE+BE SHA 对、启动说明、已完成/未完成场景、预算实账及回滚入口；不得替用户宣告最终满意。
